Privacy Policy

Last updated: May 2026

Summary

Vet is designed to be 100% local and privacy-first. No data is collected, transmitted, or stored by us. Everything runs on your machine.

Data Collection

Vet does not collect any data. The CLI tool runs entirely on your local machine. It makes zero network calls during verification.

  • No telemetry
  • No analytics
  • No crash reports
  • No usage tracking
  • No personal information collection
  • No cookies on this website

Code Analysis

All code analysis happens locally. Your code never leaves your machine. Vet reads staged changes from your local git repository and processes them entirely in memory.

Payment Processing

For Pro and Team subscriptions, payment is processed by Stripe. We do not store or process payment information. Stripe's privacy policy applies to payment data.

Third-Party Services

The only third-party service used is npm for package distribution. Downloading the package from npm is subject to npm's privacy policy.

Changes

If this policy changes, we will update the date above and post a notice on our GitHub repository.

Contact

For privacy concerns: privacy@vet.dev
