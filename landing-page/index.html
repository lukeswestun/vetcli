What Vet checks

🔄 Hallucination Detection

Catches fake npm packages, imaginary APIs, and made-up imports that AI models frequently hallucinate.

🔒 Security Scanning

Detects hardcoded secrets, eval(), SQL injection, shell injection, and other security vulnerabilities.

🎨 Style Consistency

Checks naming conventions against your project's git history. Catches casing inconsistencies automatically.

⚡ Pre-Commit Hook

Runs automatically on every commit. Zero-config setup. Blocks bad AI code before it enters your repo.

🔐 100% Local

Zero network calls during verification. Your code never leaves your machine. Privacy-first by design.

🚀 Fast

Runs in under 500ms for most projects. You won't even notice it's there — until it catches something.
